# InnerWorld
###这片世界以广袤大陆为主体，大小不一的巨型湖泊散落大地，不存在真正意义上连通一体的大洋。

斯威特族先祖定居在一座巨型湖泊沿岸。在斯威特本土语言里，“海”的定义是：广阔无垠、环抱陆地、能够给予族群庇护的巨大水体。这座湖泊辽阔无边，视线所及看不到对岸，先民无从分辨湖泊与大洋，顺理成章将它认作“大海”。长久以来，族人滋生出对“海神”的敬畏与崇拜，以海神信仰为核心的教会就此诞生，深深扎根于斯威特王国。

玩家的家族世代居住在斯威特王国下辖的海岬湾自治领。玩家的祖父是一名痴迷测绘的探险家。为完成完整的世界海岸地图，他沿着众人公认的“海岸线”长途远航。数年之后，他携大量手绘地图归来，将所有图纸拼接合拢，惊人的事实浮出水面：这条连绵不断的水岸最终首尾相接围成闭环，被水岸圈住的中心区域是水域，而非陆地——他们世代信奉的“大海”，仅仅是一座巨型内陆湖。

为证实猜想，祖父耗尽半生青春，踏遍已知大地各处。最终彻底确认：全世界不存在真正的大洋，所有被民众称作“海”的水域，本质上都只是规模不等的湖泊。

祖父将全套世界测绘地图上交王国议会，图纸辗转呈至国王手中。国王认可这份颠覆性的地理发现，下令启动教科书改革，准备向国民普及全新地理认知。

但王权之上，教会拥有凌驾国王的巨大权威。教皇的统治合法性根植于海神信仰，“世界没有真正的海洋”这一结论，会直接动摇教会赖以立足的神学根基。教会迅速出手叫停教育改革，将这套地理理论定性为异端学说，随后罗织颠覆神权的罪名，囚禁国王。

目睹强权压制真相，祖父悲愤不已。依托自己在海岬湾自治领的声望，联合自治领内部主张脱离王国的独立派系，开始筹划海岬湾独立运动。

玩家的父亲无法认同祖父激进的选择。在自治领正式掀起独立浪潮前夕，他带着尚在襁褓中的主角，远离故土，就此漂泊异乡。
